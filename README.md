# legio-virt-iter-navigator

travelers guide for twin planet oscillation: a one-page reference for **virt iter legio**, the noise engineering three-algorithm stereo oscillator (harm, sawx, bass) for the legio platform. every control by its panel tag, flavor and tang per algorithm drawn out, chorus, sync, phase mod, patches and specs.

source: the noise engineering virt iter legio manual.

part of the [legio starsystem](https://mellotom.github.io/legio-navigator/) in the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with noise engineering.
